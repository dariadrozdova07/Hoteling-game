# Конкуренция кофеен на графе
Учебная игра на основе модели пространственной конкуренции. Игрок и компьютер, используя свой стартовый капитал, по очереди выбирают, где открыть кофейню, а затем одновременно назначают цены. Побеждает участник, обладающий наибольшим капиталом к концу игры.

## Основная идея
Город представлен в виде графа. Его вершины означают доступные для открытия кофеен места, а ребра - улицы, вдоль которых распределены покупатели. Каждый покупатель выбирает кофейню, учитывая цену кофе, затраты на дорогу и личные предпочтения.

В центре города потенциальный спрос выше, но открытие кофейни и аренда дороже. Задача игрока - учитывать вышеперечисленные факторы и выбирать такие места и цены, чтобы к концу игры накопить больше капитала, чем соперник.
## Как проходит раунд
1. **Игрок выбирает** свободную вершину на карте города и открывает там кофейню
2. **Соперник**, зная выбор игрока, размещает свою кофейню
3. **Игрок и соперник одновременно назначают цены**, зная расположение обеих кофеен
4. **Подсчитываются итоги раунда:** спрос, прибыль каждой кофейни и улицы, с которых пришли покупатели
## Модель
Неориентированный, связный, взвешенный граф G = (V, E), где V - множество вершин (мест для кофеен), а E - множества ребер (улиц с покупателями).

Покупатель, расположенный в точке х на ребре e идет в кофейню с наибольшей полезностью:

```math
U_i(x) = v(x) - p_i - T_i(x) + \varepsilon
```

- v - ценность чашки кофе для покупателя
- p - цена
- T - затраты на дорогу до кофейни
- eps - личные предпочтения потребителя, учитываются по логит-модели
Покупатель может пойти в более дальнюю кофейню, если экономия в цене превосходит транспортные издержки
**Выбор кофейни.** При заданных местах и ценах соперника рациональная кофейня выбирает цену, которая максимизирует ее прибыль:
  
```math
\pi_{i}(p_{i},p_{i})=(p-{i}-c_{i})\,Q_{i}(p_{i},p_{i})-F_{i}
\quad\longrightarrow\quad \max_{p_{i}}
```
